# AstroBioRythme

Site statique en français pour calculer le bio-rythme des 72 Génies. L'application s'ouvre directement depuis `index.html` et peut être hébergée sur GitHub Pages.

## Publication

Le workflow GitHub Actions publie automatiquement le site à chaque push sur `main`. Une fois GitHub Pages activé avec la source **GitHub Actions**, le site est accessible à l'adresse :

https://hubertdoubt.github.io/astro-biorhythme/

Le calcul des planètes utilise Astronomy Engine depuis jsDelivr ; une connexion Internet est nécessaire pour ces positions. Le calcul du Soleil reste disponible hors ligne.
